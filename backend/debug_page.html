题目描述

给你平面直角坐标系中的四个点，判断这四个点是否构成一个正方形   

输入描述:

第一行输入四个整数xix_ixi​ (0≤xi≤100000 \le x_i \le 100000≤xi​≤10000)
第二行输入四个整数yiy_iyi​ (0≤yi≤100000 \le y_i \le 100000≤yi​≤10000)

输出描述:

如果可以构成正方形，输出"It's a square"
否则输出"Not a square"
示例1

输入

复制 
0 0 2 2
0 2 0 2

输出

复制 
It's a square
示例2

输入

复制 
0 1 5 6
1 6 0 5

输出

复制 
It's a square
示例3

输入

复制 
0 0 7 7
0 3 0 3

输出

复制 
Not a square
